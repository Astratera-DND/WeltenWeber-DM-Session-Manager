# Keyboard shortcuts

Shortcuts don't fire while you are typing in a text box.

| Keys | What happens |
|---|---|
| **Space** | Master play / stop (music and SFX) |
| **Shift+S** | Fire the selected Quick Fire sound |
| **Ctrl+Enter** | START ALL: layout, script, music and SFX |
| **Ctrl+P** | Open the projector |
| **Ctrl+R** | Reload the folders |
| **Ctrl+B** | Add a blanking box (only when blanking is switched on) |
| **Ctrl+M** | Add a recording mark |
| **Ctrl+Tab** | Quick Add: search all visuals in your campaign |
| **Alt+A** | Brush tool (press again to switch off) |
| **Alt+Shift+A** | Clear the drawing |
| **Delete** | Remove the selected picture or blanking box from the stage |

In the **Reorder** and **Playlist** windows: **Ctrl+A** selects all shown tracks, and **Delete** removes the selected playlist entries.
