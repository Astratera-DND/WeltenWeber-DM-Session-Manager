# Demo project

Point the tool's **Sessions Folder** (top bar → 📁 Browse…) at this `sample_project` folder.

* `Demo Session / 010_Market` – a market scene with layouts, NPC portraits, music, SFX and a playlist.
* `Demo Session / 020_Softlight Botanics` – a shop interior with its own music and layouts.
* `Demo Session / 030_Forgarm` – an entrance scene; one picture is **linked** from the market scene (blue entry).

`sample_libraries/` next to it shows the genre-folder library (`music/Ambient`, `music/Combat`, `sfx/Forge`, `sfx/Tavern`).

The music was generated with Suno and the pictures with Midjourney. They are included only to demonstrate the tool and are
not covered by the MIT license, so please don't reuse them elsewhere.
